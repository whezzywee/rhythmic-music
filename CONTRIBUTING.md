# Contributing to Rhythmic Music

First off, thank you for considering contributing! Every contribution matters — from bug reports to code to translations.

## How Can I Contribute?

### 🐛 Reporting Bugs
- Check the [existing issues](https://github.com/YOUR_USERNAME/rhythmic-music/issues) first to avoid duplicates
- Use the **Bug Report** issue template
- Include your OS, app version, and steps to reproduce

### 💡 Suggesting Features
- Use the **Feature Request** issue template
- Explain what the feature does and why it matters
- If it's inspired by another app, mention that (we love learning from good ideas)

### 🔧 Submitting Code

1. **Fork** the repository
2. **Create a branch** for your change: `git checkout -b feature/my-feature`
3. **Make your changes** — keep them focused and small
4. **Test** on your platform (Windows or Linux)
5. **Commit** with a clear message: `git commit -m "Add: brief description"`
6. **Push** and open a **Pull Request**

### 🌍 Translations
- Translations are in the `localization/` directory
- Feel free to add or improve translations for your language

## Development Setup

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (stable channel)
- Git
- For Linux: `mpv` package

### Getting Started
```bash
git clone https://github.com/YOUR_USERNAME/rhythmic-music.git
cd rhythmic-music
flutter pub get
flutter run -d windows    # or -d linux
```

## Code Style

- Follow the existing code conventions in the project
- Run `flutter analyze` before submitting a PR
- Keep PRs focused — one feature or fix per PR

## Commit Messages

Use clear, descriptive commit messages:
- `Fix: description` — for bug fixes
- `Add: description` — for new features
- `Update: description` — for changes to existing features
- `Docs: description` — for documentation changes
- `Refactor: description` — for code restructuring

## Community Guidelines

- Be respectful and constructive
- Help others when you can
- Give credit where it's due
- See our [Code of Conduct](CODE_OF_CONDUCT.md) for details

## Questions?

Open a [Discussion](https://github.com/YOUR_USERNAME/rhythmic-music/discussions) or an issue. No question is too small.
